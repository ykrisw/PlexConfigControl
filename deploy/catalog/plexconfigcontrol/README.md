# PlexConfigControl

Browse existing PlexConfigControl backups, verify archive contents, and review
verification results in History. The archive folder is mounted read-only.
This edition works with existing archives. Creating backups, restoring the
live Plex configuration and managing snapshots require the full edition.

## Install

1. Select **English** or **Polski**. English is preselected.
2. Choose the existing archive folder and set the panel password.
3. Leave the default port unless it conflicts. If you have a trusted HTTPS
   certificate for the NAS address you use, select it in the form.
4. Click **Install**, then open the panel and sign in. Your installation
   language is the panel's initial language.

The app keeps settings, the password verifier and history in its own iXVolume.
The selected archive folder must be readable by the app user (UID and GID 568).

## Instalacja

1. Wybierz **Polski** lub **English**. Domyślnie formularz zaczyna po angielsku.
2. Wybierz istniejący folder archiwów i ustaw hasło do panelu.
3. Zostaw domyślny port, jeśli jest wolny. Jeśli masz zaufany certyfikat HTTPS
   pasujący do używanego adresu NAS, wybierz go w formularzu.
4. Kliknij **Install**, otwórz panel i zaloguj się. Panel zacznie w wybranym języku.

Ten wariant wyświetla i weryfikuje istniejące kopie. Wyniki znajdziesz w Historii.
Folder archiwów jest dostępny tylko do odczytu. Do tworzenia kopii, przywracania
konfiguracji Plex i obsługi migawek służy pełna wersja aplikacji.
